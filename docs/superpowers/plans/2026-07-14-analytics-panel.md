# Analytics Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a toggleable "Analytics" HUD panel to H₂Grid with three stacked sections — Network (bar chart of node counts by H₂ taxonomy color, live-linked to the existing status/region filters), Markets (a live hydrogen-industry stock tracker), and Intel (a scripted-refresh hydrogen news feed) — without touching the existing globe/filter/detail behavior.

**Architecture:** One new additive classic-script module, `js/08-analytics.js`, loaded last (after `hud.js`), following the same pattern as `hud.js`/`iea-layer.js`: it reads globals defined by earlier modules (`D`, `COLORS`, `map`, `statusFilter`, `regionFilter`, `REGION_GROUPS`, `applyFilters`, `escapeHtml`, `escapeAttr`) and patches `applyFilters` to keep the Network bars live. Markets uses a live client-side fetch (same try/catch/fallback shape as `loadLiveStations()` in `07-live.js`). Intel is static data (`js/news-data.js`) regenerated by a new dependency-free Python script (`build-news.py`), mirroring the existing `build-iea.py` pattern.

**Tech Stack:** Vanilla JS (no build step), MapLibre GL (unchanged), Python 3 stdlib only for `build-news.py`.

## Global Constraints

- Classic scripts sharing one global lexical scope — do not wrap new modules in IIFEs/ES-modules (see `README.md` "Editing rules").
- Load order = dependency order — `js/08-analytics.js` loads last (after `hud.js`) since it patches `applyFilters` and reads globals from every earlier module.
- Hydrogen taxonomy colors (`COLORS` in `js/01-core.js`, `--h-*` in `style.css`) must not be restyled — reuse them for any new data-encoded color.
- Static site, no backend, no build step.
- Dev-only refresh scripts (`build-iea.py`, `build-news.py`) require Python 3 on PATH and are rerun manually, never scheduled.
- `FINNHUB_KEY` ships empty — unlike NREL's `DEMO_KEY`, Finnhub has no public demo key. The Markets section must degrade to a fallback state, never a broken UI.
- No new npm/pip dependencies: `build-news.py` uses only Python stdlib (`urllib`, `xml.etree.ElementTree`, `json`, `re`, `os`, `sys`).
- This machine's Python is a Windows Store alias stub, not a real interpreter — verify with `python3 --version` or `python --version` before relying on it; install a real Python 3 first if needed.

```js
/* ==========================================================================
   H2Grid · Analytics panel
   Network composition bars, live stock tracker, hydrogen industry news.
   Additive HUD module — patches applyFilters, wires the new toggle button.
   Browser classic scripts share one global lexical scope, so map, helpers &
   state from core/filters are visible here. Load order matters — see
   index.html (must load after 03-filters.js and hud.js).
   ======================================================================= */

function wireAnalyticsToggle() {
  const btn = document.getElementById("analytics-btn");
  const panel = document.getElementById("analytics-panel");
  if (!btn || !panel) return;
  btn.addEventListener("click", () => {
    const opening = panel.hidden;
    panel.hidden = !opening;
    btn.classList.toggle("active", opening);
  });
}

function initAnalyticsPanel() {
  wireAnalyticsToggle();
}

if (document.readyState === "loading") document.addEventListener("DOMContentLoaded", initAnalyticsPanel);
else initAnalyticsPanel();
```

```js
const TAXONOMY_ORDER = ["green", "blue", "pink", "turquoise", "gray_blue", "brown", "mfg"];
const TAXONOMY_LABELS = {
  green: "Green", blue: "Blue", pink: "Pink", turquoise: "Turquoise",
  gray_blue: "Gray", brown: "Brown", mfg: "Mfg"
};

function computeColorCounts() {
  const feats = [
    ...D.upstream.features, ...D.production.features, ...D.manufacturing.features,
    ...D.storagePoints.features, ...D.pipelines.features, ...D.endUse.features
  ];
  const counts = {};
  TAXONOMY_ORDER.forEach((k) => { counts[k] = 0; });
  feats.forEach((f) => {
    const p = f.properties;
    if (statusFilter !== "all" && p.statusClass !== statusFilter) return;
    if (regionFilter !== "all" && !(REGION_GROUPS[regionFilter] || []).includes(p.region)) return;
    if (counts.hasOwnProperty(p.color)) counts[p.color]++;
  });
  return counts;
}

function renderNetworkBars() {
  const el = document.getElementById("analytics-network");
  if (!el) return;
  const counts = computeColorCounts();
  const max = Math.max(1, ...TAXONOMY_ORDER.map((k) => counts[k]));
  el.innerHTML = TAXONOMY_ORDER.map((k) => {
    const n = counts[k];
    const pct = Math.round((n / max) * 100);
    return `<div class="bar-row">
      <span class="bar-label">${TAXONOMY_LABELS[k]}</span>
      <span class="bar-track"><span class="bar-fill" style="width:${pct}%;background:${COLORS[k]}"></span></span>
      <span class="bar-count">${n}</span>
    </div>`;
  }).join("");
}

function initAnalyticsPanel() {
  wireAnalyticsToggle();
  renderNetworkBars();
}
```

```js
// Free tier: https://finnhub.io/register — this ships empty (unlike NREL's
// DEMO_KEY, Finnhub has no public demo key) and shows a "configure API key"
// fallback until you set it.
const FINNHUB_KEY = "";
const STOCK_TICKERS = [
  { symbol: "PLUG", name: "Plug Power" },
  { symbol: "BE", name: "Bloom Energy" },
  { symbol: "BLDP", name: "Ballard Power" },
  { symbol: "ITM.L", name: "ITM Power" },
  { symbol: "NEL.OL", name: "Nel ASA" },
  { symbol: "FCEL", name: "FuelCell Energy" },
  { symbol: "APD", name: "Air Products" },
  { symbol: "LIN", name: "Linde" },
  { symbol: "CMI", name: "Cummins" },
  { symbol: "GTLS", name: "Chart Industries" }
];
let marketsInterval = null;

async function fetchQuote(symbol) {
  const res = await fetch(`https://finnhub.io/api/v1/quote?symbol=${encodeURIComponent(symbol)}&token=${FINNHUB_KEY}`);
  if (!res.ok) throw new Error(`Finnhub HTTP ${res.status}`);
  return res.json(); // { c: current price, dp: percent change, ... }
}

async function renderMarkets() {
  const el = document.getElementById("analytics-markets");
  if (!el) return;
  if (!FINNHUB_KEY) {
    el.innerHTML = `<div class="markets-fallback">Configure a free Finnhub API key in js/08-analytics.js for live quotes. <a href="https://finnhub.io/register" target="_blank" rel="noopener">Get one free</a></div>`;
    return;
  }
  try {
    const quotes = await Promise.all(STOCK_TICKERS.map((t) => fetchQuote(t.symbol).then((q) => ({ ...t, q }))));
    el.innerHTML = quotes.map(({ symbol, name, q }) => {
      const up = (q.dp || 0) >= 0;
      return `<div class="stock-row">
        <span class="stock-symbol">${escapeHtml(symbol)}</span>
        <span class="stock-name">${escapeHtml(name)}</span>
        <span class="stock-price">${q.c != null ? q.c.toFixed(2) : "—"}</span>
        <span class="stock-change ${up ? "up" : "down"}">${q.dp != null ? (up ? "+" : "") + q.dp.toFixed(2) + "%" : "—"}</span>
      </div>`;
    }).join("");
  } catch (err) {
    console.warn("Markets fetch failed:", err);
    el.innerHTML = `<div class="markets-fallback">Live quotes unavailable — check your connection or API key.</div>`;
  }
}

function startMarketsPolling() {
  renderMarkets();
  if (marketsInterval) clearInterval(marketsInterval);
  marketsInterval = setInterval(renderMarkets, 60000);
}

function stopMarketsPolling() {
  if (marketsInterval) clearInterval(marketsInterval);
  marketsInterval = null;
}

function initAnalyticsPanel() {
  wireAnalyticsToggle();
  renderNetworkBars();
  renderMarkets();
}
```

**Interfaces:**

- [ ] **Step 1: Create build-news.py**

```python
#!/usr/bin/env python3
"""H2Grid — hydrogen news refresh.
Pulls public RSS feeds from IEA, Bloomberg Green, NYT Climate, S&P Global,
Reuters Energy, Hydrogen Insight, and Recharge News; filters to
hydrogen-relevant entries; asks Claude for a one-line HUD-voice summary of
each; writes js/news-data.js. Rerun manually whenever you want fresh
headlines — nothing here runs on a schedule.

Usage:
  ANTHROPIC_API_KEY=sk-... python3 build-news.py
  python3 build-news.py --selftest      # offline check, no network/API calls
"""
import json, os, re, sys, urllib.request
import xml.etree.ElementTree as ET

FEEDS = [
    ("IEA", "https://www.iea.org/news/rss"),
    ("Bloomberg Green", "https://feeds.bloomberg.com/green/news.rss"),
    ("NYT Climate", "https://rss.nytimes.com/services/xml/rss/nyt/Climate.xml"),
    ("S&P Global", "https://www.spglobal.com/commodityinsights/en/rss-feed/energy-transition"),
    ("Reuters Energy", "https://www.reutersagency.com/feed/?best-sectors=energy"),
    ("Hydrogen Insight", "https://www.hydrogeninsight.com/rss"),
    ("Recharge News", "https://www.rechargenews.com/rss"),
]

KEYWORDS = re.compile(r"hydrogen|electroly[sz]er|fuel cell|\bh2\b|green steel", re.I)

MAX_CANDIDATES = 10
MAX_OUTPUT = 8

OUT_PATH = os.path.join(os.path.dirname(os.path.abspath(__file__)), "js", "news-data.js")


def fetch_feed(url, timeout=15):
    req = urllib.request.Request(url, headers={"User-Agent": "H2Grid/1.0"})
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        return resp.read()


def parse_rss(xml_bytes):
    """Return [{title, link, summary, date}] from an RSS 2.0 payload."""
    root = ET.fromstring(xml_bytes)
    items = []
    for item in root.iter("item"):
        title = (item.findtext("title") or "").strip()
        link = (item.findtext("link") or "").strip()
        summary = (item.findtext("description") or "").strip()
        summary = re.sub(r"<[^>]+>", "", summary)  # strip any embedded HTML
        date = (item.findtext("pubDate") or "").strip()
        if title and link:
            items.append({"title": title, "link": link, "summary": summary, "date": date})
    return items


def relevant(entry):
    return bool(KEYWORDS.search(entry["title"] + " " + entry["summary"]))


def collect_candidates():
    candidates = []
    for source, url in FEEDS:
        try:
            entries = parse_rss(fetch_feed(url))
        except Exception as err:
            print(f"skip {source}: {err}", file=sys.stderr)
            continue
        for e in entries:
            if relevant(e):
                candidates.append({**e, "source": source})
    return candidates[:MAX_CANDIDATES]


def summarize(entry, api_key):
    """One-line HUD-voice summary via the Claude API. Falls back to the
    feed's own snippet (truncated) if no API key is configured."""
    if not api_key:
        snippet = entry["summary"] or entry["title"]
        return snippet[:140]
    body = json.dumps({
        "model": "claude-sonnet-5",
        "max_tokens": 60,
        "messages": [{
            "role": "user",
            "content": (
                "Write ONE punchy sentence (max 140 characters, no quotes, no "
                "hashtags) summarizing this hydrogen-industry article for a "
                "mission-control HUD readout:\n\n"
                f"Title: {entry['title']}\nSnippet: {entry['summary']}"
            )
        }]
    }).encode("utf-8")
    req = urllib.request.Request(
        "https://api.anthropic.com/v1/messages",
        data=body,
        headers={
            "content-type": "application/json",
            "x-api-key": api_key,
            "anthropic-version": "2023-06-01"
        }
    )
    with urllib.request.urlopen(req, timeout=30) as resp:
        data = json.load(resp)
    return data["content"][0]["text"].strip()[:140]


def build_records(candidates, api_key):
    out = []
    for entry in candidates[:MAX_OUTPUT]:
        out.append({
            "source": entry["source"],
            "headline": entry["title"],
            "summary": summarize(entry, api_key),
            "url": entry["link"],
            "date": entry["date"]
        })
    return out


def write_js(records):
    with open(OUT_PATH, "w", encoding="utf-8") as f:
        f.write("// Generated by build-news.py — do not hand-edit. Rerun the script for fresh headlines.\n")
        f.write("window.HYDROGEN_NEWS = ")
        json.dump(records, f, indent=2, ensure_ascii=False)
        f.write(";\n")


def selftest():
    """Offline check: RSS parsing + keyword filter + summary fallback, no network."""
    sample_xml = b"""<?xml version="1.0"?>
    <rss><channel>
      <item><title>Green hydrogen plant opens in Texas</title>
        <link>https://example.com/a</link>
        <description>A new &lt;b&gt;electrolyzer&lt;/b&gt; facility begins operating.</description>
        <pubDate>Mon, 01 Jul 2026 00:00:00 GMT</pubDate></item>
      <item><title>Local bakery wins award</title>
        <link>https://example.com/b</link>
        <description>Unrelated to energy.</description>
        <pubDate>Mon, 01 Jul 2026 00:00:00 GMT</pubDate></item>
    </channel></rss>"""
    entries = parse_rss(sample_xml)
    assert len(entries) == 2, f"expected 2 items, got {len(entries)}"
    assert entries[0]["summary"] == "A new electrolyzer facility begins operating.", entries[0]["summary"]
    rel = [e for e in entries if relevant(e)]
    assert len(rel) == 1 and rel[0]["title"].startswith("Green hydrogen"), "keyword filter should keep only the hydrogen item"
    summary = summarize({**rel[0], "source": "Test"}, api_key="")
    assert summary == "A new electrolyzer facility begins operating.", "no-key fallback should reuse the snippet"
    print("PASS  selftest: RSS parse, keyword filter, no-key summary fallback")


def main():
    if "--selftest" in sys.argv:
        selftest()
        return
    api_key = os.environ.get("ANTHROPIC_API_KEY", "")
    if not api_key:
        print("ANTHROPIC_API_KEY not set — using feed snippets instead of LLM summaries.", file=sys.stderr)
    candidates = collect_candidates()
    if not candidates:
        print("No hydrogen-relevant entries found across feeds — leaving news-data.js untouched.", file=sys.stderr)
        return
    records = build_records(candidates, api_key)
    write_js(records)
    print(f"Wrote {len(records)} headlines to {OUT_PATH}")


if __name__ == "__main__":
    main()
```
